## 🚀 التشغيل والنشر

### التشغيل المحلي:
```bash
# تثبيت التبعيات
npm install

# تشغيل بيئة التطوير
npm run dev
```

### البناء للإنتاج:
```bash
npm run build
npm start
```

### النشر على Render:
المشروع يحتوي على ملف `render.yaml` للإعداد الفوري (Render Blueprint).
- **Build Command**: `npm install && npm run build`
- **Start Command**: `npm start`
- **Port**: `3000` (أو المنفذ المحدد بواسطة `$PORT`)
- **Environment Variables**:
  - `NODE_ENV=production`
  - `GEMINI_API_KEY` (مفتاح API الخاص بنماذج الذكاء الاصطناعي Gemini)
